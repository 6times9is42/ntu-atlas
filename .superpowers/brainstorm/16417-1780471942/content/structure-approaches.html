Where should Clubs & Societies live?

Three structural approaches — pick what feels right

A

Section on the main page

Clubs appear as a new scrollable section below the freshmen checklist. Filterable by type using tabs. ~200 cards inline on the page.

B

Separate page (clubs.html)

Clubs get their own dedicated page. Main page has a prominent link/banner to it. Keeps the main page lean.

C

Modal / drawer overlay

A "Clubs & Societies" button in the nav or portals section opens a full-screen overlay with the filterable list.
